About this course

Web Design & Development introduces the process of creating websites that are clear, useful, responsive, and accessible. Students learn how web pages are structured with HTML, styled with CSS, and enhanced with basic JavaScript. The course also explores page layout, navigation, forms, tables, usability, and accessibility. Practical activities help students turn design ideas into working web pages and test them across different devices and ways of navigating.

Learning outcomes

By the end of the course, students should be able to:

  1. Explain the basic structure of a web page and how browsers display HTML.
  2. Use semantic HTML to organise text, links, images, lists, tables, and forms.
  3. Apply CSS to style pages and create clear, responsive layouts.
  4. Use basic JavaScript to add simple interactions to a website.
  5. Apply accessibility and usability principles, then test pages using a keyboard and browser tools.
